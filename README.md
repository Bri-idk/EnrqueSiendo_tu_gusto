# Mi Recomendador Personal: Reseñas & Selección de Videojuegos

## 1. Descripción del Proyecto

Este proyecto es una página web responsiva desarrollada como práctica individual. El sitio presenta una selección recomendada de videojuegos interactivos, aplicando maquetación con HTML5, componentes de Bootstrap 5, estilos personalizados en CSS3 y lógica de datos básica mediante JavaScript.

---

## 2. Fase de Planificación (Pienso)

- **¿Qué voy a recomendar?**: Una selección de videojuegos destacados para diversas plataformas.
- **¿A quién va dirigida la página?**: A jugadores y entusiastas que buscan recomendaciones rápidas y reseñadas.
- **¿Qué información tendrá cada recomendación?**: Nombre del juego, género, año de lanzamiento, calificación y disponibilidad.
- **¿Qué interacción tendrá el usuario?**: Visualizar las tarjetas de recomendaciones, navegar entre secciones e inspeccionar datos dinámicos a través de la consola del navegador.

---

## 3. Tecnologías Utilizadas

- **HTML5** (Estructura semántica)
- **CSS3** (Estilos personalizados)
- **Bootstrap 5** (Layout responsivo y componentes)
- **JavaScript ES6** (Variables y tipos de datos básicos)
- **Git & GitHub** (Control de versiones)
- **Asistente de IA** (Soporte para guía y aprendizaje)
